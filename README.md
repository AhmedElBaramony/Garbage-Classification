# Garbage Classification Using CNNs

## Project Overview
This project develops a smart system to classify different types of garbage (cardboard, glass, metal, paper, plastic, and trash) using convolutional neural networks (CNNs). The goal is to improve recycling efficiency and contribute to a cleaner environment by automating the waste sorting process. Our model is compared with a reference model employing transfer learning to evaluate the effectiveness of our custom CNN architecture.

## Objectives
- Develop a garbage classification model with at least 80% accuracy.
- Implement and test the AI model on a standardized dataset.
- Compare the model's performance with a reference model to gauge improvements.
